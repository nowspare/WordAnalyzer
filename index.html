What it does

Every tool you need to read a document properly.

Built for writers, researchers, translators, and anyone who works with text in more than one script.

Document extraction

PDF, DOCX, XLSX, PPTX, TXT, CSV, JSON, and Markdown. Text is pulled out page by page, sheet by sheet, slide by slide.

Image OCR

JPG, PNG, WEBP, and GIF are read with Tesseract. Confidence scores are shown alongside the extracted text.

Full statistics

Words, unique words, characters, letters, sentences, paragraphs, reading time, and average word length — all computed from the actual extracted text.

Word frequency

Ranked word lists, percentages, and a visual cloud. Click any word to jump straight to its occurrences in the editor.

RTL, LTR, and reversal

Switch the editor between left-to-right and right-to-left. Reverse text by grapheme cluster, reverse word order, or restore the original instantly.

Exports

Download extracted text, edited text, word frequency, statistics, sentences, search results, and a generated PDF report.

Search and replace

Search across one file, selected files, or all files. Replace single occurrences or every occurrence, with undo.

Nothing leaves the browser

There is no backend. Files are read with the browser's File API and never uploaded to a server.

Privacy

Your files stay on your device.

This is a statement of what the code actually does, not a marketing promise.

How files are processed

When you choose a file, the browser's File API reads it directly from your disk into memory. Extraction, OCR, search, replacement, and statistics all run as JavaScript inside the page. No network request is made with file contents, extracted text, or analysis results.

What is stored

The application keeps only two things in localStorage: your theme preference and your text-direction preference. Files and extracted text are never written to persistent storage. They live in memory for the current session and disappear when you close the tab or remove the file.

Third-party scripts

The page loads open-source libraries from public CDNs: PDF.js, Mammoth, SheetJS, JSZip, jsPDF, and Tesseract. These requests download code only. No file data is sent to those CDNs. You can self-host the libraries if you prefer to avoid the CDN request entirely.

What we do not do

No accounts. No analytics. No tracking pixels. No cookies beyond the two preference values above. No server logs of document contents.
